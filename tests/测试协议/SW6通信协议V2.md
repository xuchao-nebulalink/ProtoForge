# 六足平台通信协议 V2\.0（SW6 / sixfoot）

> 适用于 6 自由度并联（Stewart）六足平台。
> 
> 6 路作动腿协同支撑台面，合成台面 **X / Y / Z 平移 \+ U\(Rx\) / V\(Ry\) / W\(Rz\) 旋转** 共 6 自由度位姿。
> 
> 



---



## 1. 系统概述



- **受控对象**：台面 6 自由度位姿 —— **X / Y / Z（平移）** 与 **U=Rx / V=Ry / W=Rz（旋转）**

- **下位机职责**：位姿正 / 逆运动学解算、各腿伺服定位、实时上传当前位姿（可选附 6 路杆长）

- **上位机能力**：位姿控制、伺服 / 回零 / 限位 / 坐标系 / 参数 / 杆长补偿烧录与读取 / 波形 / 轨迹 / 数据记录 / 对准扫描等完整控制，实时位姿 / 杆长接收

本协议采用 **2 类帧并存**，靠**首字节天然区分**，可在同一物理链路（串口 / 网口）上共存，互不冲突：



|帧类|用途|首字节|校验|频率|
|---|---|---|---|---|
|ASCII 控制|设备 / 运动 / 查询 / 配置指令（上位机 ⇄ 下位机）|`$` \(0x24\)|checksum\-8|低频|
|二进制实时|位姿 / 杆长 / 速度等（下位机 → 上位机，一包同帧）|`0x81`|CRC\-16/UMTS<br>|高频|



> **设计原则**：所有「设置 / 动作 / 查询」类功能一律走 `$` ASCII 帧（带 checksum，抗干扰、易调试）；只有高频实时数据走 **`0x81` 单一二进制帧**（位姿 / 杆长 / 速度等同包，按类型字节自描述，可扩展）。离散 ADC 等低频量用 `$TADq` 等 ASCII 查询；离散状态轮询由 `$STAq` 状态字一次性获取（见 4\.8），不引入无校验的单字节命令。
> 
>

## 3. 帧分流（首字节路由）



接收端读首字节即可判定帧类型并选择对应解析器：



|方向|首字节|帧类型|解析|
|---|---|---|---|
|上位机 → 下位机|`0x24` \(`$`\)|ASCII 控制命令|读到 `;` 后再读 2 位 HEX 校验和|
|下位机 → 上位机|`0x24` \(`$`\)|ASCII 回复 / 事件|同上|
|下位机 → 上位机|`0x81`|实时数据流|按长度字段解析 typed record，见 6\.1\~6\.4|



> 其它首字节一律丢弃并继续寻找帧头。

## 4. ASCII 命令协议



### 4.1 帧格式



```Plain Text
$<CmdName>,<arg1><type>,<arg2><type>,...;<XX>
│ │         │                            │
│ │         └─ 参数字段（逗号分隔，值带类型后缀） │
│ └─ 命令名（仅大小写字母）                    │
└─ 帧头 0x24                              └─ 2 位大写 HEX 校验和
```



- **帧头**：`$`（0x24）

- **命令名**：仅大小写字母（A–Z / a–z），最长 15 字符

- **参数**：`<值><类型后缀>`，逗号分隔（见 4\.3）

- **结束符**：`;`，其后紧跟 2 位 HEX 校验和；**无** `\r\n`，读完 2 位校验即帧结束，接收端遇下一个 `$` 重新同步

- **最大帧长**：256 字节

> 下文「参数」列的 `<…>` 仅为占位，真实帧不含尖括号（如 `$MOV,Xs,1.5f;XX`）。
> 
> 



### 4.2 校验定义（checksum\-8）



- **范围**：`$` 到 `;`（含 `$` 与 `;`）之间**所有字节**逐字节累加，取低 8 位

- **表示**：2 个**大写** HEX 字符，附在 `;` 之后

- 公式：`checksum = (从 '$' 到 ';' 的所有字节之和) & 0xFF`

### 4.3 参数类型后缀



|后缀|类型|示例|
|---|---|---|
|`f`|float（浮点数）|`10.5f`、`-3.14f`、`0f`|
|`d`|integer（整数）|`100d`、`-5d`|
|`s`|string（字符串 / 标识符）|`Xs`、`TOOLAs`、`STARTs`|



> 位姿 / 单轴运动指令采用「轴名\(字符串\) \+ 数值\(浮点\)」成对写法，例如 `Xs,1.5f` 表示 X 轴 = 1\.5 mm。坐标系名、宏名、子命令等用字符串 `s` 后缀。
> 
> 



### 4.4 数值单位（ASCII 链路）



|量|轴|ASCII 单位|
|---|---|---|
|平移|X / Y / Z|**mm**（float）|
|旋转|U / V / W（Rx / Ry / Rz）|**rad**（float）|
|平移速度 / 加减速|X / Y / Z|**mm/s**、mm/s²|
|旋转速度 / 加减速|U / V / W|**rad/s**、rad/s²|



> 下发位姿用工程量 **mm / rad**（可经 `$PUN` 设置）；实时流的整数单位与换算见第 7 节。
> 
> 



### 4.5 命名与语法约定



全协议统一以下约定：



1. **命令名只含字母**（`[A-Za-z]`，≤ 15 字符），不含 `?`、`*`、`#`、下划线、空格等任何符号。

2. **设置 / 查询同名靠后缀区分**：设置用 `XXX`，查询用 `XXXq`（如 `VEL` 设置 / `VELq` 查询）；**`XXXq`**** 默认回 ****`XXX`**** 所设的同名字段值**（如 `WGC` 设循环次数、`WGCq` 即回该次数）。

3. **轴选择**：单轴 / 多轴命令用「轴名 \+ 数值」成对，即 `<轴>s,<值>f`，可连续多对指定多轴；**省略轴参数 = 作用于全部 6 轴**。轴名 ∈ `X,Y,Z,U,V,W`。

4. **按元素查询回复回显标识**：每个按元素（轴 `<轴>s` / 通道 `<通道>d` / 线 `<线>d` / 发生器·表 `<…>d` 等）的查询，回复**逐个回显「标识 \+ 值」**（如 `Xs,5f`），以便上位机明确每个值属于哪个元素；**省略元素参数 = 回全部**（轴类按 **X,Y,Z,U,V,W** 序回全 6 轴）。布尔量用 `d`（0 / 1）。全局单值（如平台速度 `VLSq`、计时器 `TIMq`）无元素，直接回值。

5. **多段 / 带子项的命令把子命令降为字符串参数**：如宏 `MAC,<子>s,<名>s`、波形 `WAV,<表>d,<类型>s,…`，避免命令名里出现空格。

6. **开关量统一用 ****`<0/1>d`**：`1`=开 / 启用 / 是，`0`=关 / 禁用 / 否。

### 4.6 回复格式与错误模型



下位机回复统一格式：



```Plain Text
$<CmdName>,0x<ERRCODE>,<query_data>;<XX>
```



- **成功**：`ERRCODE = 0x00000000`

- **非查询命令成功回复**：`$<Cmd>,0x00000000;XX`（全协议默认 ACK，后续各命令表不再逐条重复）

- **查询命令成功回复**：`$<Cmd>,0x00000000,<data...>;XX`，`data` 见各命令「查询回复」说明

- **失败**：`$<Cmd>,0x<ERRCODE>;XX`（不带 `query_data`）

**「查询回复」列记法**（第 5 节统一沿用，列中只写 `…` 之后的 data 部分）：



|记法|含义|完整回复示例|
|---|---|---|
|`…`|成功前缀 `$<Cmd>,0x00000000,`|—|
|`6×f`|全 6 轴各回 `<轴>s,<值>f` 对（X,Y,Z,U,V,W 序）；查单 / 部分轴只回对应轴的对|`$POSq,0x00000000,Xs,1.5f,Ys,0f,Zs,0f,Us,0f,Vs,0f,Ws,0f;XX`|
|`6×d`|同上，值为整数 / 布尔（`0`/`1`）|`$SVOq,0x00000000,Xs,1d,Ys,1d,Zs,1d,Us,1d,Vs,1d,Ws,1d;XX`|
|`…,<元素>,<v>`|按元素查询回显「标识 \+ 值」（通道 / 线 / 发生器等同理）|`$TAVq,0x00000000,2d,3.3f;XX`（通道 2 = 3\.3）|
|`…,<v>f` / `…,<n>d`|全局单值（无元素，如平台速度、计时器、通道总数）|`$VLSq,0x00000000,10f;XX`|



> 完整帧 = `$<Cmd>` \+ `,0x00000000`（成功码）\+ data \+ `;XX`（校验）；失败则不带 data。
> 
> 单轴 / 单元素查询同样回显标识：`$VELq,Xs;` → `$VELq,0x00000000,Xs,5f;XX`。
> 
> 



### 4.7 错误码



|错误码|含义|
|---|---|
|`0x00000000`|成功|
|`0x01000000`|内部配置错误|
|`0x01000004`|内部使用错误|
|`0x02000000`|未找到命令|
|`0x02000001`|帧头错误|
|`0x02000002`|重复帧头|
|`0x02000003`|尾字符错误|
|`0x03000001`|未知命令名|
|`0x03000002`|命令名为空|
|`0x03000003`|命令名溢出|
|`0x03000004`|缺少参数|
|`0x03000005`|参数过多|
|`0x03000009`|缺少参数类型|
|`0x0300000B`|参数类型与值不匹配|
|`0x0300000C`|用户传入参数错误|
|`0x04000001`|伺服未开启|
|`0x04000002`|未回零 / 未参考|
|`0x04000003`|超出软限位|
|`0x04000004`|运动中拒绝该操作|
|`0x04000005`|处于急停 / 故障状态|
|`0x04000006`|坐标系 / 参数 / 表项不存在|


> 编码段位约定：`0x00`=成功，`0x01`=内部错误，`0x02`=帧 / 协议错误，`0x03`=解析 / 参数错误，**`0x04`****=运动 / 状态错误（V2 新增段）**。错误码为稳定契约，新增按兼容方式追加，不复用 / 改义已有编号。
> 
> 


### 4.8 `$STAq` 状态字


`$STAq` 一次往返返回一个 **32 位状态字**（以 8 位 HEX 表示），覆盖运动 / 就绪 / 伺服 / 错误等离散状态，避免高频多次轮询：



- 查询：`$STAq;B8`

- 回复：`$STAq,0x00000000,0x<STATUS>;XX`，例如 `$STAq,0x00000000,0x00000025;67`

状态字位定义（bit0 = 最低位）：


|bit|掩码|含义|
|---|---|---|
|0|0x00000001|运动中（任一轴）|
|1|0x00000002|已到位（全部到位）|
|2|0x00000004|已回零|
|3|0x00000008|存在错误（ERR ≠ 0）|
|4|0x00000010|波形发生器运行中|
|5|0x00000020|急停 / 故障状态|
|6|0x00000040|对准 / 扫描过程运行中|



> 例：`0x00000025` = bit0 \+ bit2 \+ bit5 = 运动中 \+ 已回零 \+ 急停 / 故障状态。
> 
>

### 5.1 系统与标识


> 说明：本节命令用于设备识别、状态查询、配置保存 / 恢复、杆长补偿烧录 / 读取、错误处理和安全停止。
> 本节中的 `EAX` / `LLC` 针对**物理腿 / 驱动器**，使用腿号 `1~6`，不使用平台自由度 `X/Y/Z/U/V/W`。
> `LLC` **直接烧录进控制器系统**（掉电保持），**无需**再发 `$SAV`。补偿为加到该腿杆长上的偏移（mm）；建议固件按 `有效杆长 = 名义/测量杆长 + 补偿` 使用，符号方向由固件定义并保持稳定。未给出的腿保持原值；省略腿号的查询回全部 6 腿（`1~6` 升序）。

| 命令     | 参数                 | 含义 / 查询回复                                                      |
| ------ | ------------------ | -------------------------------------------------------------- |
| `IDN`  | 无                  | 设备标识 / 握手。回复 `…,<型号>s,<YYMM>s,<序列号>s`                  |
| `VER`  | 无                  | 固件版本。回复 `…,<版本>s`                                              |
| `ERR`  | 无                  | 查询当前错误码。回复 `…,0x<ERRCODE>`                                     |
| `CLR`  | 无                  | 清除错误 / 急停 / 故障锁存状态。清除成功后设备恢复到可重新使能状态                           |
| `HLPq` | 无                  | 查询支持的命令列表。回复 `…,<数量>d,<cmd1>s,<cmd2>s,...`                     |
| `STAq` | 无                  | 查询状态字，状态字定义见 4.8。回复 `…,0x<STATUS>`                             |
| `SAV`  | `<域>s` 可省略         | 保存当前配置到掉电存储。省略 `<域>` 时默认 `ALL`                                 |
| `RST`  | `<域>s` 可省略         | 恢复已保存的工作配置。省略 `<域>` 时默认 `ALL`                                  |
| `ITD`  | `<域>s` 可省略         | 恢复默认配置。省略 `<域>` 时默认 `ALL`                                      |
| `EAX`  | `<腿>d,<0/1>d`（可多组） | 启用 / 禁用物理腿或驱动器。腿号范围 `1~6`，`1`=启用，`0`=禁用                        |
| `EAXq` | `<腿>d` 可省略         | 查询物理腿 / 驱动器启用状态。省略腿号时回复 6 组腿状态：`…,1d,<v>d,2d,<v>d,...,6d,<v>d` |
| `LLC`  | `<腿>d,<补偿>f`（可多组） | **烧录**物理腿杆长补偿到系统，单位 mm。腿号 `1~6`；可一次多组，未给出的腿保持原值 |
| `LLCq` | `<腿>d` 可省略         | **读取**系统中已存杆长补偿。省略腿号时回复 `…,1d,<v>f,...,6d,<v>f`；指定腿号时只回对应组 |
| `HLT`  | 无                  | 平滑停止所有运动，按减速度停止，不进入故障状态                                        |
| `STP`  | 无                  | 急停，立即停止所有运动，并进入急停 / 故障锁存状态                                     |
| `STF`  | 无                  | 强制停止并进入故障状态，用于软件保护或严重异常处理                                      |
| `RBT`  | 无                  | 重启控制器                                                          |
| `RTO`  | 无                  | 准备断电：停止实时流，保存必要运行状态，进入安全断电状态                                   |
| `TIM`  | `<值>f`             | 设置 / 重置计时器，单位由固件定义，建议使用秒                                       |

### 5.3 伺服与闭环

> 说明：本节命令作用对象为**物理腿 / 驱动器**，统一使用腿号 `1~6`。
> 不建议使用 `X/Y/Z/U/V/W` 做伺服开关，因为它们是平台虚拟自由度，不是实际驱动器。

| 命令     | 参数                | 含义 / 查询回复                                      |
| ------ | ----------------- | ---------------------------------------------- |
| `ONTq` | `<轴>s` 可省略        | 查询平台到位状态。回复 6×`d`，`1`=到位，`0`=未到位               |
| `BRA`  | `<腿>d,<0/1>d` 可多组 | 物理腿 / 驱动器刹车开关。`1`=刹车释放 / 允许运动，`0`=刹车抱死 / 禁止运动  |

### 5.4 速度 / 加减速

### 5.7 坐标系（六足关键）

坐标系用于描述六足平台的运动参考关系。系统固定存在基座坐标系 `BASE`。用户可定义工具坐标系 `TOOL` 和工件坐标系 `WORK`，并指定当前启用的工具系、工件系和旋转中心。

功能坐标可通过 `KLN` 建立**父子链接关系**：把某坐标系挂到父坐标系之下，其位姿在父系基础上叠加解释，形成 `BASE → 父 → 子` 的坐标链；父系取 `BASE` 即以 BASE 为根（等价于解除链接）。

### 5.12 轨迹控制

> 轨迹控制用于上位机一次性下发多个平台位姿点，由下位机缓存、检查并执行。
> 轨迹点作用对象为平台自由度 `X/Y/Z/U/V/W`，不直接下发 6 条物理腿长度。
> 轨迹默认在 `BASE` 坐标系下解释；如需 `WORK / TOOL` 轨迹，建议上位机转换为 `BASE` 位姿后下发。

| 命令     | 参数                                             | 含义 / 查询回复                                                 |
| ------ | ---------------------------------------------- | --------------------------------------------------------- |
| `TGC`  | `<轨迹>d` 可省略                                    | 清除轨迹。省略轨迹号时清除全部轨迹。运动中拒绝执行                                 |
| `TGA`  | `<轨迹>d,<点号>d,<插补>d,<速度>f,<停留ms>d,<轴>s,<值>f...` | 写入轨迹点。点号从 `0` 开始；点号等于当前点数时表示追加，小于当前点数时表示覆盖                |
| `TGF`  | `<轨迹>d`                                        | 结束轨迹写入并检查轨迹。检查通过回复 `…,1d,0d,0d`；失败回复 `…,0d,<错误点>d,<原因码>d` |
| `TGS`  | `<轨迹>d`                                        | 启动轨迹。轨迹必须已执行 `TGF` 且检查通过                                  |
| `TST`  | `<轨迹>d,<动作>d`                                  | 控制轨迹运行。`0`=停止，`1`=暂停，`2`=继续                               |
| `TGIq` | `<轨迹>d` 可省略                                    | 查询轨迹信息。回复 `…,<轨迹>d,<点数>d,<状态>d,<当前点>d,<当前循环>d,<剩余容量>d`    |
| `TLC`  | `<轨迹>d,<循环次数>d`                                | 设置轨迹循环次数。`1`=执行一次，`0`=无限循环                                |
| `TLCq` | `<轨迹>d` 可省略                                    | 查询轨迹循环次数。回复 `…,<轨迹>d,<循环次数>d`                             |
| `TGT`  | `<周期>d`                                        | 设置轨迹插补周期，单位为伺服周期数。通常 `1d` 表示每个伺服周期插补一次                    |
| `TGTq` | 无                                              | 查询轨迹插补周期。回复 `…,<周期>d`                                     |

#### `TGA` 轨迹点格式

```Plain Text
$TGA,<轨迹>d,<点号>d,<插补>d,<速度>f,<停留ms>d,<轴>s,<值>f...;XX
```

参数说明：

| 参数             | 含义                     |
| -------------- | ---------------------- |
| `<轨迹>d`        | 轨迹编号，从 `1` 开始          |
| `<点号>d`        | 点编号，从 `0` 开始           |
| `<插补>d`        | 当前点相对上一点的插补方式          |
| `<速度>f`        | 当前段速度；`0f` 表示使用全局速度参数  |
| `<停留ms>d`      | 到达该点后的停留时间，单位 ms       |
| `<轴>s,<值>f...` | 平台位姿点，轴为 `X/Y/Z/U/V/W` |

规则：

1. 第 `0` 点建议给完整 `X/Y/Z/U/V/W`。
2. 后续点未给出的自由度，默认沿用上一点的值。
3. 下位机内部应补齐成完整 6 自由度位姿。
4. 轨迹运行中不允许修改正在运行的轨迹。

#### 插补方式 `<插补>d`

| 值   | 含义                              |
| --- | ------------------------------- |
| `0` | 点到点运动。各自由度同步到达目标点，不保证 XYZ 路径为直线 |
| `1` | 笛卡尔直线插补。`XYZ` 直线插补，`U/V/W` 线性插补 |

#### `TGF` 检查回复

检查通过：

```Plain Text
$TGF,0x00000000,1d,0d,0d;XX
```

检查失败：

```Plain Text
$TGF,0x00000000,0d,<错误点>d,<原因码>d;XX
```

原因码：

| 原因码 | 含义             |
| --- | -------------- |
| `0` | 无错误            |
| `1` | 轨迹为空           |
| `2` | 点号不连续          |
| `3` | 平台软限位超限        |
| `4` | 物理腿行程超限        |
| `5` | 逆运动学无解         |
| `6` | 速度 / 加速度约束无法满足 |
| `7` | 插补模式不支持        |
| `8` | 未回零 / 未参考      |
| `9` | 伺服未开启          |

#### 轨迹状态 `<状态>d`

| 状态  | 含义        |
| --- | --------- |
| `0` | 空轨迹       |
| `1` | 写入中       |
| `2` | 检查通过，等待启动 |
| `3` | 运行中       |
| `4` | 暂停        |
| `5` | 执行完成      |
| `6` | 错误        |
| `7` | 用户停止      |

## 6. 实时二进制数据流（0x81）



> 下位机通过 **`0x81` 单一二进制帧**上传全部高频实时数据（连接 / 上电后自动推送）。一帧内可包含：**6 路实际位姿**（默认必有）、可选 **6 路理论位姿**、**6 路实际杆长**、**6 路理论杆长**、**6 路杆长速度**、**8 路 AD 模拟量**；后续扩展量（如力传感）只需新增类型码，仍走同一 `0x81` 帧。
> 
> 
> 
> 数据域由若干 **5 字节 typed record** 顺序拼接：第 1 字节为**类型码**，后 4 字节为 **int32 小端有符号数值**。可选数据块由 **`$RSE` 单字节掩码**（见 6\.3）控制；**实际位姿始终发送**。
> 
> 



### 6.1 帧结构（0x81）



```Plain Text
+------+------+----------------------------+-----------+------+
| 帧头 | 长度 |          数据域            |  CRC16    | 帧尾 |
+------+------+----------------------------+-----------+------+
| 0x81 | N×5  | N 条 × (类型1B + 数值4B)   | 2 字节小端| 0x55 |
+------+------+----------------------------+-----------+------+
```



- **长度字段**：数据域字节数，**必须是 5 的倍数**（N 条 record × 5）。
- **整帧长度** = 5 \+ 长度 = 1 \+ 1 \+ N×5 \+ 2 \+ 1。
- **默认**（仅实际位姿）：N = 6，长度 = `0x1E`（30），整帧 **35 字节**。
- 接收端**不要写死 35 字节**：先读「长度」，校验 `% 5 == 0`，再按 6\.2 逐条解析；record 条数须与当前 `$RSE` 掩码一致（N = 6 \+ 6×popcount\(mask & 0x0F\) \+ 8×\(\(mask & 0x10\) ? 1 : 0\)，即位姿 / 杆长各块 6 条、AD 块 8 条），否则丢弃并重找帧头。



### 6.2 Typed Record 编码（每条 5 字节）



```Plain Text
+------+----------------------------------+
| TYPE |  VALUE (int32 LE, 4 bytes)       |
+------+----------------------------------+
| 1 B  |  BYTE0 .. BYTE3                  |
+------+----------------------------------+
```



```Plain Text
type  = data[0]
value = (int32_t)(data[1] | (data[2] << 8) | (data[3] << 16) | (data[4] << 24))
```



- 同一帧内**每种 TYPE 最多出现 1 次**；下位机按 6\.3 固定顺序组帧。
- 除下表「原始码值」类外，工程量统一 **`value ÷ 1,000,000`** 得显示单位（平移 / 杆长 → mm，旋转 → rad，杆长速度 → mm/s，AD 模拟量 → V）。
- 32 位有符号范围 ±2,147,483,647，余量充足。



#### 类型码表



位姿 / 杆长各类数据占 **连续 6 个 TYPE**（块内偏移 0\~5 对应 X,Y,Z,U,V,W 或腿 1\~6）；AD 模拟量占 **连续 8 个 TYPE**（块内偏移 0\~7 对应通道 0\~7）：



|TYPE 范围|含义|轴 / 腿 / 通道|传输单位|显示换算|
|---|---|---|---|---|
|`0x01`\~`0x06`|实际位姿|X,Y,Z,U,V,W|nm / µrad|÷ 1e6 → mm / rad|
|`0x07`\~`0x0C`|理论位姿|X,Y,Z,U,V,W|nm / µrad|÷ 1e6 → mm / rad|
|`0x0D`\~`0x12`|实际杆长|腿 1\~6|nm|÷ 1e6 → mm|
|`0x13`\~`0x18`|理论杆长|腿 1\~6|nm|÷ 1e6 → mm|
|`0x19`\~`0x1E`|杆长速度|腿 1\~6|nm/s|÷ 1e6 → mm/s|
|`0x1F`\~`0x26`|AD 模拟量|通道 0\~7|µV|÷ 1e6 → V|
|`0x27`\~`0xFF`|**预留扩展**|固件定义|固件定义|对接时文档化|



### 6.3 流内容掩码（`$RSE` / `$RSEq`）



控制 `0x81` 帧中**除实际位姿外**各可选块是否编入每帧。掩码为 **1 字节**（8 bit，bit0 最低位）；**实际位姿恒发**，不占掩码位。



|命令|参数|含义 / 查询回复|
|---|---|---|
|`RSE`|`<mask>d`|设置掩码（0\~255，位或，见下表）|
|`RSEq`|无|查询掩码。回复 `…,0x<MM>`（**2 位 HEX，单字节**）|



**掩码位定义**



|bit|掩码|含义|TYPE 块|
|---|---|---|---|
|0|0x01|理论位姿|`0x07`\~`0x0C`|
|1|0x02|实际杆长|`0x0D`\~`0x12`|
|2|0x04|理论杆长|`0x13`\~`0x18`|
|3|0x08|杆长速度|`0x19`\~`0x1E`|
|4|0x10|AD 模拟量|`0x1F`\~`0x26`|
|5\~7|—|预留|—|



- **默认**：`0x00`（仅 6 路实际位姿）
- **例**：`0x03` = bit0+bit1 → 理论位姿 + 实际杆长，每帧 18 条 record（95 B）
- **设置**：`$RSE,3d;XX` 与掩码 `0x03` 等价
- **查询**：`$RSEq;XX` → `$RSEq,0x00000000,0x03;XX`



**组帧顺序**（bit 置 1 时按序追加）：实际位姿（始终）→ bit0 块 → bit1 → bit2 → bit3 → bit4（AD）



|掩码|N|长度|整帧|
|---|---|---|---|
|`0x00`|6|`0x1E`|35 B|
|`0x01`|12|`0x3C`|65 B|
|`0x02`|12|`0x3C`|65 B|
|`0x03`|18|`0x5A`|95 B|
|`0x0F`|30|`0x96`|155 B|
|`0x10`|14|`0x46`|75 B|
|`0x1F`|38|`0xBE`|195 B|





### 6.4 CRC\-16 定义



|参数|值|
|---|---|
|算法|CRC\-16/UMTS|
|多项式|0x8005（x¹⁶ \+ x¹⁵ \+ x² \+ 1）|
|初始值|0x0000|
|Refin / Refout|false|
|Xorout|0x0000|

## 9. 附录



### 9.1 设计要点



1. 两类帧首字节互斥（`0x24` / `0x81`），同线无歧义共存。

2. 所有设置 / 动作 / 查询走 ASCII（checksum\-8）；高频实时数据**统一走 **`0x81`** typed record 帧**（CRC\-16/UMTS，5 字节 / 条）。

3. `0x81` 可选块由 **`$RSE` 单字节掩码**（6\.3）按 bit 控制。

4. 命名统一：命令名只含字母、`q` 后缀查询、开关用 `<0/1>d`、多段命令子命令字符串化（见 4\.5）。

5. 错误码为稳定契约，新增按兼容方式追加（V2 新增 `0x04` 运动 / 状态错误段），不复用 / 改义已有编号。
